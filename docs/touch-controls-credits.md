# Touch controls artwork

The native-style touch buttons in `port/textures/touch/` use icons from
[game-icons.net](https://game-icons.net/), licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/):

| Button | Icon | Author |
| - | - | - |
| Jump | `wingfoot` | Lorc |
| Punch | `punch-blast` | Lorc |
| Ground pound | `quake-stomp` | Lorc |
| Camera | `fluffy-cloud` | Lorc |
| Pause | `pause-button` | Guard13007 |

The icons were recolored white and placed on a translucent disc with a gold rim.
The menu bars, stick base and star knob are original shapes.

To regenerate the PNGs, render each button at 256x256 with a transparent
background and save it under `port/textures/touch/<Name>.png`.
